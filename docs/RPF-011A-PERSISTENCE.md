# RPF-011A: run evidence persistence

This migration adds run provenance, frozen reproducer, patch attempts, executions, artifact metadata, ordered events and reports to the existing PostgreSQL schema. Existing auth models remain unchanged except for the optional run relation. Artifact bytes are not stored or verified here. Only server-side deterministic policy can decide a verdict; this schema alone does not authenticate evidence or authorize reports.

PostgreSQL constraints bind runs to snapshots in the same repository and executions to attempts in the same run, validate digest formats, event sequence and attempt/count bounds, and prevent mutation of run provenance. Database triggers reject update, deletion and truncation of immutable evidence. Pending approvals and unfinished attempts can advance; finalized approvals and completed attempts cannot be rewritten. These controls apply to ordinary database operations; privileged database owners can alter or disable triggers. Configure production roles and access separately.

Evidence deletion is intentionally blocked, including cascading deletion. A separate authorized retention design must coordinate private artifact deletion and database records; no retention bypass or object-store cleanup is implemented here. Database constraints do not prove hashes match external bytes, runner authenticity, tenant authorization, ordering of lifecycle transitions or verdict correctness. Those remain separate work.

The SQL integration test is destructive to its target namespace and must only be run in a freshly created disposable PostgreSQL database. Apply `prisma/migrations/20260625203212_init/migration.sql`, then `prisma/migrations/20261030000100_run_evidence/migration.sql`, then `integration/rpf011a-evidence.sql` with `psql -X -v ON_ERROR_STOP=1`. Never target the development or production database. The test uses synthetic data and rejects 24 negative cases. Prisma migrate deploy and status were also tested against a fresh disposable PostgreSQL database; a second deploy reported no pending migrations. This test does not exercise an isolated fixture runner.
